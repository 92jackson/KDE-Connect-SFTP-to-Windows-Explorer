# KDE Connect SFTP to Windows Explorer

A small Windows workaround for KDE Connect's **Browse this device** feature.

Windows Explorer does not natively support `sftp://` links, so KDE Connect may show an error when trying to browse a connected device.

This script:

- Registers as the Windows SFTP protocol handler.
- Receives the SFTP URL generated by KDE Connect.
- Extracts the host, port, username, temporary password and remote path.
- Mounts the supplied location as a Windows drive using SSHFS-Win.
- Opens the mounted drive in Windows Explorer.
- Uses KDE Connect's live connection details, so IP addresses and ports are not hardcoded.

## Requirements

Install:

- WinFsp
- SSHFS-Win

Official releases are available from their respective project websites, or using:
```
winget install SSHFS-Win.SSHFS-Win
```

## Installation

Save the script somewhere under your user profile, for example:

    %USERPROFILE%\Scripts\kdeconnect-sftp-mount.ps1

Then open **PowerShell as Administrator** and register the SFTP protocol:

    reg add "HKCR\sftp" /ve /d "URL:SFTP Protocol" /f
    reg add "HKCR\sftp" /v "URL Protocol" /d "" /f

Register the script as the SFTP handler, replacing `<SCRIPT_PATH>` with the full path to the script:

    reg add "HKCR\sftp\shell\open\command" /ve /d 'powershell.exe -NoProfile -ExecutionPolicy Bypass -File "<SCRIPT_PATH>" "%1"' /f

Example:

    reg add "HKCR\sftp\shell\open\command" /ve /d 'powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\USERNAME\Scripts\kdeconnect-sftp-mount.ps1" "%1"' /f

After registration, use:

    KDE Connect -> Browse this device

KDE Connect will supply the current SFTP connection details to the script, which will mount the device and open it in Windows Explorer.

## Drive Letter

By default, the script mounts the device as:

    P:

This can be changed by editing:

    $drive = 'P:'

inside the script.

## Troubleshooting

If you already have another SFTP compatible client installed (such as WinSCP), you may first need to unregister that as being the default app for SFTP connections, otherwise that client will likely block this script from running. After doing so, re-run the registry command registering this script (from the instructions above).
